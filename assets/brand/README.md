| File | Use |
|------|-----|

| `logo-light.svg` | Light-theme lockup — used in the repo README header |
| `icon.svg` | Square mark — avatar / favicon |
| `banner.txt` | Plain-text ASCII banner — drop into a CLI `--help` header or terminal output |

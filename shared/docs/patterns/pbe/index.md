# PBE meta-patterns

Load **≤3** concepts after lookup. Do not paste this whole list into chat. Deep essay (on demand): `../knowledge-base/01-pbe.md`.

* [Rule of Three](rule-of-three.md) - Same problem/solution in three unique situations → candidate pattern.
* [Piecemeal Pattern Creation](piecemeal-pattern-creation.md) - Ship 80% pattern value early; expand each iteration.
* [Select large-scope patterns first](large-scope-first.md) - Architecture → design → algorithms → idioms; never invert.
* [Pattern density](pattern-density.md) - Integrate complementary patterns; avoid isolated pattern counting.
* [End-to-End Pattern Use](end-to-end-pattern-use.md) - Apply patterns across requirements → design → implement → review → maintain.
* [Simple Solution Space](simple-solution-space.md) - Fewer valid choices → easier consumption of pattern assets.
* [Single Pattern – Varied Use Cases](single-pattern-varied-use-cases.md) - One pattern, many contexts via declared variability points.
* [Pattern selection driven by requirements](requirements-driven-selection.md) - Map functional reqs and NFRs to patterns via tags — not pattern shopping.

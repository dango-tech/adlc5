# Phase 1: Intake — Pattern Opportunity

## Purpose

Define scan boundaries and evidence sources before listing recurrences.

## Intake steps

### Step 1: Scan scope

Choose one:

- Repository path(s)
- Team / product area
- Recent PR range (e.g., last sprint)
- Single feature retrospective

### Step 2: Time window

Default: current iteration + prior two where evidence may appear.

### Step 3: Evidence sources

| Source | Access |
|--------|--------|
| Git history / PRs | |
| Jira epics | |
| Design docs | |
| Slack / retro notes | user-provided |

### Step 4: Domain-agnostic framing

Remind: pattern problems are stated **without** product nouns where possible.
